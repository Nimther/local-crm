<objective>
Close Pitfall 14's first half (CMP-05, D-15): `send_events.occurred_at` is provider-supplied and today does double duty — it routes the monthly partition and forms part of the dedup key — while the only check on it is that `new Date(ms)` will not throw. Bound it to a business-meaningful window before either use, keep the server's own `received_at` as the separate authority, and route rejected events to the quarantine table that plan 13-01 created.

Purpose: a manipulated or clock-skewed timestamp must not be able to place a row far outside the current-month partition window (which is what protects Phase 9's partition-attach machinery) or to sidestep dedup by varying only the timestamp.
Output: a pure, versioned-constant bounding classifier in `delivery-core`, per-event quarantine routing in the webhook worker, and tests proving a quarantined event is invisible to every counter.
</objective>
