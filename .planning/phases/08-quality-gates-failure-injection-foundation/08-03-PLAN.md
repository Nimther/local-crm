## Phase Goal

Any change to the send pipeline can be proven safe before it ships — CI blocks broken code, tests cannot touch the dev database, and every failure mode the audit names can be reproduced on demand.

This plan installs the lint gate itself and proves it can fail. Bringing the existing codebase to zero violations is the separate, mechanical job of 08-07.

## Artifacts this phase produces

- `eslint.config.js` (flat config, repo root)
- Root npm script `lint`
- Root npm script `lint:floor`
- `lint-file-floor.json` (key: `minFiles`)
- `scripts/check-lint-file-floor.mjs` (CLI + exported `checkLintFileFloor(reportJson, floor)`)
- Fixture directory `tools/lint-fixtures/` with `floating-promise.ts` and `focused-test.test.ts`
- devDependencies: `eslint`, `typescript-eslint`, `@vitest/eslint-plugin`, `eslint-plugin-react-hooks`, `eslint-plugin-import`, `eslint-plugin-no-only-tests`

<objective>
Stand up an ESLint 10 flat config with `typescript-eslint`'s `recommended-type-checked` tier over every workspace, prove it fails on a deliberate violation, and close the "checked 0 files and exited 0" hole with a version-controlled file-count floor.

Purpose: the type-aware tier is the only one that catches the async bug class the audit found in the send pipeline and the BullMQ workers (`no-floating-promises`, `no-misused-promises`, `await-thenable`, `require-await`) — a non-type-aware `recommended` config would be substantively empty for this codebase (D-05).
Output: a lint gate that is proven to fail before it is ever seen to pass.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Developer diff → CI lint gate | Any change that weakens the gate (broadened ignores, blanket disable, lowered floor) must be visible in the diff or fail a check |
| ESLint config globs → checked file set | A typo in `ignores` silently shrinks the checked set to zero with a green exit code |
| `eslint --fix` → focused-test markers | An auto-fixable `.only` rule would erase the evidence of a vacuously-green test run |
