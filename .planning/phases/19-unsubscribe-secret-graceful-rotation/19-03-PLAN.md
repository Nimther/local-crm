<objective>
Add the redaction rule D-02 requires for `UNSUBSCRIBE_TOKEN_SECRET_PREVIOUS`, so a retired signing secret can never leak into a log line or a Sentry event, and cover the primary secret's variable-shaped field name in the same edit.

Output: two new key rules in the single rule table, with parity coverage proving both compiled forms redact them identically.
