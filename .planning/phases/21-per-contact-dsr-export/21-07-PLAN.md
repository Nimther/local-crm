<objective>
Close gap G-21-2: every bodyless delete in the SPA fails with 400
FST_ERR_CTP_EMPTY_JSON_BODY, which blocks the contact erasure that UAT Test 2
needs in order to exercise the mid-session 410 export race.

Purpose: the diagnosis (`.planning/debug/ui-delete-empty-json-body-400.md`)
confirmed a single client-side cause — `apiFetch` attaches
`Content-Type: application/json` to every request, including requests that
carry no body, and Fastify 5.9.0 runs the JSON parser whenever that header is
present. One conditional in the shared helper fixes all five broken delete
actions. The server-side alternative (an empty-JSON-tolerant content-type
parser) was explicitly rejected in diagnosis: it would relax the parser
contract platform-wide, including the public event-ingestion and webhook
surfaces where signature verification already scopes parser behavior
deliberately.

Output: the fixed helper, a request-shape matrix test pinning every verb, and
a Playwright spec that walks the exact UAT Test 2 path.

Not a tracer-led plan: this is gap closure on an executed phase. The
architecture is already proven end-to-end by plans 21-01..21-06; these tasks
are surgical fixes carrying fail-first evidence instead of a new vertical
slice.
</objective>
