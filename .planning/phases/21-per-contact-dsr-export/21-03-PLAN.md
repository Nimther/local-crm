## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `events.properties` (tenant-written) → exported artifact | Freeform JSONB written by tenant integrations at ingestion; the only safe bound is to never read it |
| Postgres partition boundary → paged read | `events` is range-partitioned on `occurred_at`; an ordering that omits the partition key can skip or repeat rows across pages |
