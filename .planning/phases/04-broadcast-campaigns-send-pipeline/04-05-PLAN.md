<objective>
Build the campaign lifecycle backend: the repository (CRUD + the draft->scheduled->sending->sent/canceled state machine with locked transitions), the routes (create/update/list/get/launch/schedule/cancel/duplicate/test-send/progress/audience-breakdown/templates/senders), the workspace send-settings routes, the BullMQ producers (kickoff on launch, test on test-send), and the D-14 segment-delete block.

Purpose: This is the marketer-facing campaign API — CAMP-01…05 plus the SUBS-03 breakdown surface. It produces the kickoff jobs the 04-06 worker consumes and the test jobs the 04-04 worker consumes, and it wires the D-19 role gates and D-14 delete block. It runs entirely in apps/api, fully parallel to 04-04's worker files.
Output: campaign repository + routes + queues + settings routes + segment-delete block + state-machine tests.
</objective>

## Phase Goal (MVP user story)

**As a** marketer, **I want to** send a broadcast to a segment through a throttled, idempotent, suppression-aware queue, **so that** my emails reliably reach inboxes via SendGrid Dynamic Templates with per-message unsubscribe and frequency-cap compliance.

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-05-01 | Elevation of Privilege | a Member launching/scheduling a campaign | high | mitigate | launch/schedule/cancel/duplicate + settings PUT behind requirePermission("campaign","launch") (owner/admin only, D-19); create/edit drafts stay member-level |
| T-04-05-02 | Tampering | draft sent by accident / scheduled edited mid-flight | high | mitigate | Locked SELECT ... FOR UPDATE state machine rejects illegal transitions and in-place edits of scheduled campaigns (CAMP-03/D-08) |
| T-04-05-03 | Information Disclosure | cross-tenant campaign access via :slug | high | mitigate | resolveWorkspaceMember uniform-404 enumeration-safe pattern + withTenant RLS on every query |
| T-04-05-04 | Information Disclosure | tenant SendGrid key exposure via templates/senders route | high | mitigate | Key decrypted only server-side inside the route, never returned to the client; only template ids/sender emails are sent to the browser |
| T-04-05-05 | Denial of Service | pathological segment breakdown recompute | medium | mitigate | isQueryCanceledError 57014->4xx statement-timeout guard reused on the audience-breakdown count (same escape hatch as segments) |
