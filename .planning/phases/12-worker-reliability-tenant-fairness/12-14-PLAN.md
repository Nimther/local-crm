<objective>
Close UAT gap G-12-3: make the burst-absorption case in
`apps/worker/src/queues/__tests__/worker-autorun-default.test.ts` prove scheduler-tick
burst dedup end to end instead of asserting an all-zero kickoff queue against a
deliberately empty `campaigns` table.

Purpose: 12-12's burst case claims "a stacked burst ... drains ... without duplicated
kickoff work", but the only assertion carrying that claim (line 310) expects ZERO kickoff
jobs. With no campaign seeded, `findDueCampaignCandidates()` returns `[]` on all 20+ burst
ticks, so the dedup-bearing loop body (`campaign-scheduler.worker.ts:200-204`) executes
zero times — an all-zero kickoff queue is observed whether or not dedup works. The test's
own comment at :297-301 admits this. Postgres plumbing is ALREADY live in the file
(`ensureTestDbMigrated()` in `beforeAll`; `global-setup.ts` publishes DATABASE_URL /
SCAN_DATABASE_URL / AUTH_DATABASE_URL pre-fork); only seeded data and the assertions are
missing.

TDD note (`workflow.tdd_mode: true`): the deliverable here IS a test, so a dedicated
`type: tdd` plan with a `<feature>` block would be a category error. The RED->GREEN
discipline is preserved literally instead — Task 1 writes the exactly-one assertions
FIRST, runs them with no seed and records the observed failure, then adds the seed to turn
them green. That observed failure is the non-vacuity proof this gap exists to obtain.

Output: a burst case whose dedup assertion can fail, a named control case, a single shared
seeding fixture, and a green apps/worker suite.
</objective>
