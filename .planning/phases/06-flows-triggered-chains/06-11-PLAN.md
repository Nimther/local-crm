## Trust Boundaries

| Boundary | Description |

| canvas/detail client → API | Member attempting privileged actions; client validation is convenience only |
| contact/settings form → API | Untrusted timezone string constrained at input |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-11-01 | Elevation of Privilege | Member publishes/pauses/ejects via enabled UI control | high | mitigate | controls render disabled+tooltip for Member; server route re-checks Owner/Admin (06-04/06-09) — UI hiding is never the only control |
| T-06-11-02 | Tampering | client-only publish validation | high | mitigate | publish posts to server which re-validates; dialog renders the server-returned blocker list (Pitfall 3) |
| T-06-11-03 | Input Validation | invalid IANA timezone entered | medium | mitigate | TimezoneCombobox constrained to Intl.supportedValuesOf; server re-validates (06-07) |
</threat_model>
