## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, badge inner padding |
| sm | 8px | Gaps between form label and input, inline button groups |
| md | 16px | Default gap between form fields, card inner padding (compact) |
| lg | 24px | Card padding, gap between form sections |
| xl | 32px | Gap between page header and content, auth-card outer padding |
| 2xl | 48px | Vertical offset of auth card from viewport top region |
| 3xl | 64px | Page-level top/bottom margins on settings pages |

Exceptions: **none.** All spacing in this phase uses the scale above (Tailwind classes `p-1/2/4/6/8/12/16`, `gap-1/2/4/6/8`). Do not introduce arbitrary values (`p-[Npx]`).

## Typography

Exactly 4 sizes, 2 weights. No other size/weight combinations are permitted in this phase.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label / meta | 14px (`text-sm`) | 400 regular | 1.5 |
| Body | 16px (`text-base`) | 400 regular | 1.5 |
| Heading (section / card title) | 20px (`text-xl`) | 600 semibold | 1.2 |
| Display (page title, auth-card title) | 28px (`text-[28px]`, map to a `text-display` token) | 600 semibold | 1.2 |

Additional rules:
- Emphasis inside body text = weight 600 at the same size, never a new size.
- Form labels: 14px / 600. Helper and error text under inputs: 14px / 400.
- Masked SendGrid key (`SG.aB3x…k9Qz`) renders in the monospace stack (`font-mono`) at 14px.

## Color

Neutral-dominant B2B dashboard palette (maps onto shadcn `neutral` CSS variables).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` / `neutral-50` (`--background`) | Page background, main content surface |
| Secondary (30%) | `neutral-100` `#F5F5F5` surfaces, `neutral-200` `#E5E5E5` borders | Sidebar, card backgrounds, table header row, input borders |
| Accent (10%) | `indigo-600` `#4F46E5` (`--primary`) | See reserved list below — nothing else |
| Destructive | `red-600` `#DC2626` (`--destructive`) | Destructive actions only (see list) |

**Accent (`indigo-600`) reserved exclusively for:**
1. Primary CTA button per screen (one per screen max): «Создать воркспейс», «Отправить приглашение», «Подключить SendGrid», «Зарегистрироваться», «Войти»
2. Active nav item / active workspace in the switcher
3. Text links (invite link, «Забыли пароль?»)
4. Focus rings (`--ring`)
5. Checked/selected states of checkbox, radio, select

**Destructive (`red-600`) reserved exclusively for:**
1. «Удалить воркспейс» button + its confirmation dialog
2. «Удалить участника» action
3. «Отозвать приглашение» action
4. Inline form validation error text and error borders
5. SendGrid key status badge in error state

**Semantic status colors (badges only, not general UI):**
- SendGrid key «Активен» badge: `green-600` `#16A34A` on `green-50`
- Pending invite badge: `neutral-500` on `neutral-100`
- Email-not-verified banner: `amber-50` background, `amber-800` `#92400E` text

No gradients. No additional hues. Charts do not exist in this phase.

## Copywriting Contract

All UI copy is **Russian** (project working language and target market). Sentence case («Создать воркспейс», not «Создать Воркспейс»). Address the user with «вы» (lowercase).

### Primary CTAs (verb + noun, one per screen)

| Screen | Primary CTA |
|--------|-------------|
| Registration | «Зарегистрироваться» |
| Login | «Войти» |
| Workspace creation (onboarding) | «Создать воркспейс» |
| Invite modal | «Отправить приглашение» |
| Invite accept (existing account) | «Присоединиться к воркспейсу» |
| Invite accept (new account, D-12) | «Создать аккаунт и присоединиться» |
| SendGrid key connect | «Подключить SendGrid» |
| Password reset request | «Отправить ссылку для сброса» |
| Profile — change password | «Сменить пароль» |

### Empty states

| Element | Copy |
|---------|------|
| Onboarding checklist heading (D-23) | «Настройте воркспейс» |
| Onboarding checklist body | Чеклист с пунктами: «Подключите SendGrid» и «Пригласите команду», каждый с кнопкой перехода. Компонент проектировать расширяемым — в следующих фазах добавятся пункты про контакты и кампании. |
| Team page, no invites yet | Заголовок: «В воркспейсе пока только вы» · Тело: «Пригласите коллег — они получат письмо со ссылкой для входа.» · CTA: «Пригласить коллегу» |
| SendGrid not connected | Заголовок: «SendGrid не подключён» · Тело: «Подключите API-ключ вашего SendGrid-аккаунта, чтобы отправлять письма.» · CTA: «Подключить SendGrid» |

### Error states (problem + next step, never a bare code)

| Case | Copy |
|------|------|
| Login failed | «Неверный email или пароль. Проверьте данные и попробуйте ещё раз.» |
| Email already registered | «Аккаунт с этим email уже существует. Войдите или восстановите пароль.» |
| SendGrid key invalid/revoked (D-21) | «SendGrid отклонил ключ: он недействителен или отозван. Проверьте ключ в настройках SendGrid и вставьте его заново.» |
| SendGrid key missing mail.send scope (D-21) | «Ключ действителен, но не имеет права mail.send. Создайте в SendGrid ключ с доступом Mail Send и подключите его.» |
| SendGrid connect blocked by unverified email (D-02) | «Подтвердите email, чтобы подключить SendGrid. Мы отправили письмо со ссылкой — проверьте почту.» + кнопка «Отправить письмо ещё раз» |
| Invite expired (D-11) | «Срок действия приглашения истёк. Попросите администратора воркспейса отправить его заново.» |
| Invite already used / revoked | «Это приглашение больше не действует. Попросите администратора воркспейса отправить новое.» |
| Generic server error | «Что-то пошло не так. Попробуйте ещё раз — если ошибка повторится, обновите страницу.» |

### Destructive confirmations

| Action | Confirmation copy |
|--------|-------------------|
| Удаление воркспейса (D-20) | AlertDialog: «Удалить воркспейс „{название}"?» · Тело: «Все контакты, события, кампании и статистика воркспейса будут безвозвратно удалены. Введите название воркспейса, чтобы подтвердить.» · Инпут «введите название» — кнопка «Удалить воркспейс» (red-600) активна только при точном совпадении. |
| Удаление участника | AlertDialog: «Удалить {имя} из воркспейса?» · Тело: «Участник потеряет доступ ко всем данным воркспейса. Его можно пригласить снова.» · Кнопки: «Удалить участника» (red-600) / «Отмена». |
| Отзыв приглашения | AlertDialog: «Отозвать приглашение для {email}?» · Тело: «Ссылка из письма перестанет работать. Приглашение можно отправить заново.» · Кнопки: «Отозвать» (red-600) / «Отмена». |

### System copy notes

- Toasts (sonner): успех — «Приглашение отправлено», «SendGrid подключён», «Пароль изменён»; всегда существительное + глагол-результат, без восклицательных знаков.
- Баннер мягкой верификации (D-02): «Подтвердите email — без этого нельзя подключить SendGrid.» + ссылка «Отправить письмо ещё раз». Amber-стиль, dismissible на сессию.
- Маска ключа (D-22): `SG.aB3x…k9Qz` (первые символы + последние 4), рядом бейдж статуса («Активен» / «Ошибка») и кнопка «Проверить сейчас».
- Копируемая ссылка-инвайт (D-10): кнопка «Скопировать ссылку», после клика — «Скопировано».

## Component & Screen Inventory (executor reference)

| Screen / Feature | shadcn components | Key states |
|------------------|-------------------|------------|
| `/register`, `/login`, `/reset` (auth card) | card, form, input, label, button | default, submitting (disabled + spinner), field errors |
| Workspace onboarding (`create workspace`) | card, form, input, button | default, slug-collision retry is server-side (invisible to user) |
| App shell + workspace switcher (D-13, D-16) | dropdown-menu, avatar, separator | active workspace highlighted (accent), «Создать воркспейс» item at bottom |
| Onboarding checklist (D-23) | card, checkbox (read-only display), button | per-item: done / pending; extensible list |
| Team page | table, badge, dropdown-menu, dialog, alert-dialog | member rows, pending-invite rows (badge «Приглашение отправлено»), role select gated by current role (D-17/D-18) |
| Invite modal (D-10, D-11) | dialog, form, input, select, button | sent-success shows copyable link fallback |
| Invite accept page (`/invite/:token`) | card, form, button | valid / expired / revoked / already-member |
| SendGrid key settings (D-21, D-22) | card, input, button, badge, table (verified senders), tooltip | not-connected empty state, validating (spinner), connected (mask + badge + «Проверить сейчас»), error badge |
| Profile (D-24) | card, form, input, button | display name edit, change-password form |
| Delete workspace (D-20) | alert-dialog, input | type-name-to-confirm gate |
| Verify-email banner (D-02) | custom banner (amber), button | visible until verified, dismissible per session |
| Toasts | sonner | success / error variants only |
| Loading | skeleton | table rows and cards; never blank-screen spinners for page loads |

Interaction rules:
- Every mutating button gets a disabled + loading state during the request; no double-submit.
- Role gating (D-17–D-19) is reflected in UI: actions the role can't perform are **hidden** for Member (not disabled-with-tooltip) — the server remains the enforcement layer.
- Focus visible on all interactive elements (accent ring). All dialogs trap focus and close on Esc.
