<objective>
OPS-14: Bull Board behind closed administrative access, on the worker's existing loopback-only listener.

Purpose: queue observability at this send volume means being able to see stuck jobs without querying Redis by hand. D-09 makes the access control network topology rather than application code: the board binds to loopback, no port is published, and the operator reaches it through the SSH access they already have. D-10 mounts it on the worker's own health listener — which Phase 14's own code comment explicitly reserved for this phase's use.
Output: the health listener re-hosted on Fastify with its contract preserved, the board mounted on it, and read-only queue handles that close cleanly.
</objective>
