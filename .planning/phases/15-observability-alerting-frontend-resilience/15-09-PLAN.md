<objective>
OPS-19: unsaved canvas changes warn before they are lost, and a failed save is visible.

Purpose: the flow canvas already has a debounced draft save with an honest three-state indicator (Phase 6's `useAutosaveDraft`/`deriveAutosaveState`). What it does not have is any guard against navigating away with work in flight or failed, and its failure signal is a small toolbar label that is easy to miss. D-13 adds a router blocker, a native `beforeunload` guard and a persistent inline save-error banner with Retry.

Important scope clarification for the executor: D-13's "autosave/draft model explicitly rejected" means **do not invent a new draft-vs-published capability**. It does NOT mean removing the existing Phase 6 draft autosave, which is already shipped, already tested, and is the source of the dirty signal this plan consumes. Leave `useUpdateFlowDraft` and the debounce untouched.
Output: a dirty-aware navigation guard, a leave prompt, and a persistent save-error banner with Retry.
</objective>
