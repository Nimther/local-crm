<objective>
Make the closed send loop visible to the marketer (Core Value: "reliability is visible"). Three thin UI slices on top of the data the 05-03 worker writes and the 05-04 endpoints expose:

1. Campaign summary/progress now shows delivered / opened / clicked / не доставлено / unsubscribed counters (D-07), grouping bounced+dropped as "не доставлено" (D-08) — extending the existing Phase 4 progress + summary views, NOT building the per-message send log (that is Phase 7).
2. The SendGrid settings page gains a webhook-health card: connected/disconnected + "последнее событие получено N назад" + a Reconnect button (D-03).
3. The onboarding checklist gains an "Включить отслеживание доставки" item for already-connected workspaces (D-02).

Phase Goal (user story): **As a** marketer, **I want to** see accurate, deduplicated delivery outcomes for my sent emails and have bounces/spam-complaints/unsubscribes automatically suppress contacts, **so that** my stats are trustworthy and I stop mailing dead or opted-out addresses.

Purpose: Surface WBHK-04 delivery outcomes + D-03 webhook health so the marketer sees the loop is closed and trustworthy.
Output: Campaign counter API+UI, webhook health UI, onboarding item.
</objective>
