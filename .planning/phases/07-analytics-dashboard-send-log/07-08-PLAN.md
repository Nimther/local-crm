<objective>
Close verification gap 1 (ANLT-01, SC1): `CampaignDetailPage`'s `SummaryView` — the summary rendered for `sent`/`canceled` (terminal) campaigns, the state a marketer reviews most — currently shows raw delivery counts only. Plan 07-03 gave `CampaignProgress.tsx` (the live "sending" view) and `CampaignsListPage.tsx` the D-01 enrichment but explicitly left `SummaryView` untouched (documented as a scope gap in 07-03-SUMMARY.md). Extend the terminal summary with the same D-01 rate percentages, D-07 «Пропущено» excluded-reason breakdown, and D-04 send-log deep link by extracting one shared presentational component that both the sending view and the terminal view render.

Purpose: A marketer reviewing a finished campaign sees performance percentages and skipped-message reasons, not just raw counts — the "reliability is visible to the user" Core Value theme, and the last analytics phase in ROADMAP.md (nothing to defer to).
Output: A shared `CampaignMetricsSummary` component + extracted, unit-tested `bucketExcludedCounts` util; `SummaryView` and `CampaignProgress` both rendering it.
</objective>

## Phase Goal (MVP user story)

**As a** marketer, **I want to** see a finished campaign's delivered/open/click/bounce rate percentages and its skipped-message reasons on the campaign detail page, **so that** I can judge how the completed campaign performed without re-deriving percentages by hand or opening the send log.
