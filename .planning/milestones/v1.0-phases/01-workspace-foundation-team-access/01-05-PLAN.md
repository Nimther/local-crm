<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → API (connect key) | The plaintext tenant key crosses here once, over TLS; never stored plaintext |
| API → KMS | DEK generation/unwrap; KEK material never reaches the DB tier |
| API → SendGrid | Live validation of the tenant key |
| API → Postgres | Encrypted key + DEK stored in the RLS-protected workspace_sendgrid_keys table |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-17 | Information Disclosure | Tenant SendGrid key at rest / in logs | high | mitigate | KMS envelope encryption (per-tenant DEK, KEK outside the DB); Pino redaction of sendgridKey/apiKey; no plaintext column (prohibition, test-verified); plaintext DEK zeroed after use |
