<objective>
Close UAT Test 11 (06-UAT.md 2026-07-13, FLOW-01; debug session .planning/debug/autosave-error-state-stuck.md). 06-21 fixed the settled-error case (an online 4xx/5xx) but the toolbar still hangs at «Сохранение…» forever when the browser goes offline: TanStack Query v5's default `networkMode: 'online'` PAUSES the autosave mutation (mutate() dispatches status 'pending' with isPaused:true, the PATCH mutationFn is never invoked, isError never becomes true — confirmed against query-core v5.101.2 source in the debug session). `deriveAutosaveState` only models isPending/isError/dirty, so isPending wins and the toolbar dishonestly shows «Сохранение…» indefinitely. The 06-21 unit tests pass because they only cover settled inputs that never occur during an offline pause — the exact "unit-green, UAT-red" split.

Fix direction (of the two the debug session offered): model `mutation.isPaused` in the pure derivation and map a paused save to the honest error/retrying state — NOT `networkMode: 'always'`. Rationale: the isPaused approach is directly unit-testable in the node-only web lane (extend autosaveState.test.ts with the paused input shape, exactly what the gap's `missing` calls for) and leans on TanStack's built-in resume-paused-mutations-on-reconnect for the auto-retry half — whereas `networkMode: 'always'` would fire doomed fetches while offline and depend on the hook's own 4s bounded retry to own reconnection. FlowCanvas already renders the 'error' state («Не сохранено — повтор…»), so no toolbar change is needed — only the derivation and its wiring.

Work TDD-style within the pure-function lane: first the failing paused-input test, then the derivation change that makes it pass.

Purpose: the autosave indicator must never claim «Сохранение…» forever (or «Сохранено») when the save is paused offline; it must show an honest state that self-heals on reconnect.
Output: an isPaused-aware pure `deriveAutosaveState`, the hook feeding `mutation.isPaused` into it, and a regression test pinning the paused-offline shape.
</objective>
