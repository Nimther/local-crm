<objective>
Build the flow API: draft CRUD, atomic publish with server-side validation + immutable version snapshot, pause/resume/duplicate, role gating (D-23), and the restrict-delete extension so a segment referenced by a flow cannot be deleted (D-24). This delivers FLOW-06 (state machine draft→live→paused) and the FLOW-07 versioning guarantee at the API layer, and persists the FLOW-04 reentry + FLOW-05 quiet-hours-override config on the flow row.

Purpose: This is the authority layer the canvas UI (06-10/06-11) drives and the trigger/engine workers (06-05/06-06) read live/pinned versions from.
Output: apps/api/src/modules/flows/* + segment restrict-delete extension, wired into the app.
</objective>

> MVP user story (phase): **As a** marketer, **I want to** build and publish a triggered chain, **so that** it starts running automatically. This slice makes publish real and safe (immutable versions).
