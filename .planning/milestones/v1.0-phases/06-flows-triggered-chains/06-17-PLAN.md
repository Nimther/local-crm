<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Web canvas / PATCH API -> publishFlow validation | A marketer can draw a cycle (FlowCanvas `isValidConnection` only blocks self-loops/duplicate edges) or a dead-end trigger and PATCH a schema-valid-but-malformed definition; the server-side `validateFlowDefinition` at publish is the authoritative gate (never trusts a client isValid flag, Pitfall 3). |
| BullMQ flow-run-advance job -> Postgres/Redis | An enrolled run drives repeated transactions + step inserts + advance enqueues; a malformed (cyclic/dead-end) definition can make this unbounded, saturating the worker/queue and growing `flow_run_steps` without limit. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-17-01 | Denial of Service (worker/queue saturation, unbounded row growth) | flow-run-advance.worker.ts advance loop | high | mitigate | Add a per-run step budget (MAX_STEPS_PER_RUN) that force-exits a run before any further dispatch; regression test proves a run at the budget terminates with no new step/send. |
| T-06-17-02 | Tampering (of the "leaves at an exit" guarantee) via a publishable cycle | flow-validate.ts validateFlowDefinition | high | mitigate | Reject cycles reachable from the trigger at publish with `cycle_detected` (DFS + recursion stack); server-side re-validation in publishFlow returns 422 so a cyclic definition cannot go live. |
| T-06-17-03 | Denial of Service (forever reconciliation nudges on NULL current_node_id) via a dead-end trigger | flow-validate.ts + trigger evaluator/enroll insert | medium | mitigate | Reject a trigger with no outgoing edge at publish with `no_entry` (WR-02), preventing a run from ever being created with current_node_id = NULL. |

No new runtime dependencies are added (no npm/pip/cargo installs) — supply-chain threat T-06-17-SC is not applicable to this plan. No migration is added.
