Close the failed-truth root cause and the two engine correctness anti-patterns at the lowest layer of the stack (the shared Zod contract + the pure SQL compiler), so the API (03-06) and web (03-07) fixes above it stand on a boundary that actually fails closed.

Addresses SEGM-01 (attribute segments incl. tags) and SEGM-03 (the single shared engine's correctness).
Output: a fail-closed Zod boundary with an exported allow-list, a prototype-safe fail-closed compiler, LIKE-escaped substring matching, and unit tests proving all three.
</objective>
