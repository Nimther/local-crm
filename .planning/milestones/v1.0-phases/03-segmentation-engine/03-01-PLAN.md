<objective>
Build the pure, stateless heart of the segmentation engine: a SQL condition compiler (`@mega-crm/segments-core`) that turns a versioned `SegmentDefinition` JSON into one parameterized SQL `WHERE` fragment, plus the Zod contract (`packages/shared-schemas/src/segment.ts`) that every consumer validates against. No database, no HTTP — a fully unit-testable module.

Purpose: This module is what makes SEGM-03's "identical membership for campaigns and flows" structural rather than test-only — all three future call modes (count / listMembers / isMember) compile the definition through this one function. It is also the phase's primary security surface (user-authored condition trees → SQL), so it is built and unit-tested in isolation first.
Output: A new `packages/segments-core` package and a `segment.ts` shared schema, with passing pure-function unit tests including the AND/OR parenthesization regression.
</objective>
