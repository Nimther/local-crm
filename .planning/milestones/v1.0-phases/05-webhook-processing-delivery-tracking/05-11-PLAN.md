<objective>
Close the single remaining Phase 5 gap (CR-01, from 05-VERIFICATION.md / 05-REVIEW.md): `provisionEventWebhook`'s `existingWebhookId` branch only ever PATCHes the stored `sendgridWebhookId`, and a 404 (the id no longer exists on the account) is mapped to a plain `{ error: "failed" }` with no fallback to `createWebhook`'s already-built reuse-or-create machinery. Every caller then persists the stale id forward, so connect/recheck/reconnect re-PATCH the same dead id forever — permanently wedging delivery tracking for any workspace that rotated its BYO key to a different SendGrid account or deleted the platform webhook in the SendGrid dashboard, with the "Переподключить" button (the designated self-heal path) unable to recover.

Fix: treat a 404 on the PATCH-by-stored-id as "stored id is stale" and fall through to `createWebhook`, so the platform re-uses its own workspace-scoped-`friendly_name` webhook if present or creates a fresh one, and the NEW id (not the stale one) is what the callers persist.

Purpose: Reconnect/connect/recheck must always be able to self-heal a lost/rotated webhook — an ordinary operational event, not an exotic edge case — restoring the phase's core value (accurate, deduplicated delivery outcomes) for the affected workspace.
Output: A recoverable-404 fallback in `provisionEventWebhook` plus two regression tests; the full 397-test monorepo suite stays green.
</objective>

## Phase Goal

**As a** marketer whose SendGrid webhook was deleted in the dashboard or whose BYO key was rotated to a different SendGrid account, **I want to** click "Переподключить" (or reconnect on key change) and have delivery tracking automatically re-create the webhook, **so that** my emails' delivery statuses resume updating without manual database surgery.

(Gap-closure round 3 — this single plan delivers the fix and its regression coverage end-to-end, which satisfies the MVP vertical-slice principle: after it lands, a real user can recover a wedged workspace through the existing Reconnect button, which they could not do before.)
