<objective>
Close Gap 2 from 05-VERIFICATION.md (CR-01, the review's sole Critical finding):
the SendGrid auto-provisioning reuse-by-name path silently leaves delivery
tracking pointed at the wrong URL while reporting `provisionStatus: 'active'`.

Two coupled defects in `provisionEventWebhook` / `createWebhook`:
1. When it finds an existing SendGrid webhook whose `friendly_name` matches, it
   returns that webhook's id WITHOUT patching its `url` to the caller's
   `callbackUrl`. On DB-row-lost recovery the reused webhook keeps the OLD
   pathToken URL (now 404s) — tracking silently stops while the health card
   shows "active".
2. The `friendly_name` is a single global constant, so the SAME SendGrid key
   connected to two workspaces (agency/multi-brand) makes workspace B adopt
   workspace A's webhook id; a later "Переподключить" on either workspace
   repoints the SHARED webhook, killing the other workspace's tracking while it
   still shows connected.

Fix (both parts, per the verification `missing` items):
- Workspace-scope the `friendly_name` (append a short workspace discriminator)
  so each workspace only ever matches/creates/patches its OWN webhook.
- When an existing webhook is matched by the (scoped) `friendly_name`, PATCH its
  `url` to the caller's `callbackUrl` before returning, whenever it differs.

This requires threading `workspaceId` into `provisionEventWebhook` and its two
production callers.

Purpose: restore "accurate, deduplicated delivery outcomes" for the affected
workspace and remove the false-positive "active" health status that masks the
failure.
Output: repoint-on-reuse + workspace-scoped naming in the provisioning module,
callers updated, existing tests kept green, and two new regression tests.

Coverage audit (gap-closure scope): GOAL = phase truth #1 (events arrive on the
workspace's per-tenant URL, reused-webhook repoint case) → this plan. REQ =
WBHK-01 (per-tenant webhook URL + provisioning), WBHK-04 (events update message
status / are surfaced) → this plan. RESEARCH/CONTEXT = D-05 (our own
independently-named webhook, never touching a tenant's pre-existing ones), D-01
(graceful degradation preserved) → this plan. No unplanned items; full-phase
requirement coverage already satisfied by executed plans 05-01..05-05.
