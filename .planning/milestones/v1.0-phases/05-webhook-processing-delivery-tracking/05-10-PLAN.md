Include how to create a Restricted Access key with both scopes.

    - Failure-diagnosis note: if provisioning still fails, the UI now shows the reason (missing_scope / cap_reached / failed) and the operator can find the redacted SendGrid status+body in the api process logs (added in 05-08).
    - Security note: never paste a real tenant key into the runbook or any committed file; the tunnel exposes the receiver publicly but every event is ECDSA-signature-verified against the raw body before processing — do not disable that.
