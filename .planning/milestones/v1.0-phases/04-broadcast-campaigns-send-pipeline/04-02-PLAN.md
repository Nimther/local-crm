<objective>
Make tenant SendGrid credentials and dynamic-template listing usable by the send pipeline: extract the envelope-encryption client into a new shared `@mega-crm/kms` package (so the worker process can decrypt a tenant's key at dispatch time — apps/worker has no source path into apps/api), and extend the existing `sendgrid-client.ts` with a live "list dynamic templates" call for the campaign template picker (D-16).

Purpose: 04-04's send-dispatch worker (a separate process) must decrypt the tenant's BYO key to call `mail/send` (SEND-05); it cannot reach apps/api's `kms/client.ts`. This mirrors the Phase-2 precedent that extracted `tenant-context` and `contacts-core` into shared packages exactly because the worker could not import apps/api source. The template-list call feeds the campaign builder's template combobox.
Output: `@mega-crm/kms` package, updated apps/api imports, `listTenantSendGridTemplates`.
</objective>
