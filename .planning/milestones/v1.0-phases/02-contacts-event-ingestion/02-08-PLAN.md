Complete the phase's UI: the CSV import wizard (upload → mapping → dry-run preview → apply/progress → report) with navigable-away progress and an error-report download, the import history list, and the live event feed on the contact card that makes "events are arriving" visible for integration debugging (D-14). ## Phase Goal

**As a** marketer, **I want to** build and maintain my contact base through the UI, CSV import, and a server-side API — while my product backend streams freeform behavioral events — **so that** my contacts are created and enriched in real time and every contact carries an accurate subscription status.

This is the final slice: after it a marketer can import a CSV through a guided, safe wizard and watch a contact's events stream into its card — completing all three ingestion paths' user-facing surfaces.

Purpose: The wizard is how non-technical marketers seed their base; the event feed gives the immediate reliability feedback the Core Value promises and becomes the seed of the Phase 7 full timeline.
Output: CSV wizard + history UI, the contact event-feed read route + UI, wired to 02-06/02-07 backends.
</objective>
