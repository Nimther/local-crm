## Claude's Discretion

- Нормализация email, формат external_id, формат префикса API-ключа
- CSV: кодировки, разделители, лимит размера файла, потоковый парсинг
- Схема таблиц, партиционирование events, индексы, RLS-политики
- Очередь: BullMQ + Redis, структура джоб, ретраи, идемпотентность, rate limiting Event API
- Семантика client-supplied timestamp и дедупликация событий
- UX редактора кастомных свойств, валидации форм
