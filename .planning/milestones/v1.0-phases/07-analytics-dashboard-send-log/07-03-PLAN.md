## Phase Goal

**As a** marketer, **I want to** see end-to-end email performance — per campaign, per flow step, per contact, and across my whole workspace, down to the status of every individual message — **so that** I can tell what is working and always answer why a contact did or did not receive an email.

This plan delivers campaign metrics (ANLT-01): a complete vertical slice enriching the existing campaign summary with rate percentages, an excluded-reason breakdown, a send-log deep link, and per-row list metrics — all read from counters Phases 4-5 already maintain. No schema change.

## Artifacts this phase produces

- `computeRate(numerator, denominator): number | null` in `apps/web/src/lib/rates.ts` (returns null on zero denominator)
- `excludedBreakdown` field on the campaign progress API response (array of `{ reason, count }`)
- Enriched `CampaignProgress` summary (rates + «Пропущено» row + send-log link) and `CampaignsListPage` row metrics

<objective>
Enrich the existing campaign summary and list with the D-01 rate percentages, the D-07 excluded-reason breakdown row, and the D-04 send-log deep link — reading the counters already on the campaigns row (delivered/opened/clicked/bounced/unsubscribed) plus a new exclusion-reason grouping over the sends ledger.

Purpose: A marketer sees campaign performance as both counts and percentages, with skipped messages accounted for by reason, without leaving the campaign page.
Output: A shared rate helper, an excluded-breakdown API addition, and enriched campaign summary + list UI.
</objective>
