## Phase Goal

**As a** marketer, **I want to** see end-to-end email performance — per campaign, per flow step, per contact, and across my whole workspace, down to the status of every individual message — **so that** I can tell what is working and always answer why a contact did or did not receive an email.

This plan delivers the workspace summary dashboard (ANLT-04): a complete vertical slice from a rollup-backed read API through the Recharts trend/growth charts + KPI cards + mini-lists to the workspace home page, replacing WorkspaceHome while preserving the onboarding checklist.

## Artifacts this phase produces

- `dashboard.repository.ts` (`getWorkspaceDashboard(period)`) and `dashboard.routes.ts` (`GET /api/workspaces/:slug/dashboard?period=7|30|90`)
- `WorkspaceDashboard` (new index route), `TrendChart` + `GrowthChart` (first Recharts usage in the codebase), KPI cards, mini-lists
- Recharts dependency added to `apps/web`

<objective>
Add a rollup-backed dashboard endpoint (trend series from workspace_daily_rollup, growth from contacts.created_at, period KPIs, recent-campaigns/active-flows mini-lists) and build the workspace dashboard UI with Recharts, making it the workspace index route while preserving the onboarding checklist (D-08a).

Purpose: A marketer lands on a workspace and immediately sees send/deliver/open trends over a chosen period and contact-base growth — the at-a-glance health of their marketing (ANLT-04) — without heavy on-the-fly scans (D-08b).
Output: A tenant-safe dashboard API, the dashboard page with two charts + KPI cards + mini-lists, and the home-route swap.
</objective>
