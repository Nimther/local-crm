<objective>
Close G-12-1: five repeatable-tick workers register their schedulers and then never consume a single job, because each one forwards a run-loop option that is undefined under the production call shape and thereby overwrites the library's own enabling default.

Purpose: this is the phase blocker. Scheduled campaigns never kick off, analytics and flow reconciliation never run, the send reconciler never resolves an ambiguous send, and partition maintenance never extends the horizon — while every one of them logs as registered at boot and shows a growing wait list instead of an error. Two of the five have been silently dead since Phase 9 and Phase 11 respectively; the pattern then spread to three more during this phase. The existing registration suites cannot catch it because every one of them suppresses the run loop explicitly and so never exercises the shape the running process uses.
Output: the five factories fixed under one idiom, a regression test that constructs them the way the composition root does and proves consumption, and a recorded decision on the accumulated wait-list backlog.
</objective>

## Gap being closed

`G-12-1` (blocker, UAT test 1). Diagnosed root cause, already confirmed empirically — do not re-derive it:

The five factories build their worker with an options object that always carries the run-loop key, taking its value from the factory's own optional parameter. The composition root calls each factory with one argument, so that parameter defaults to an empty object and the key's value is `undefined`. The library merges its defaults with the caller's options using a plain object assign, so an own property holding `undefined` replaces the enabling default rather than falling back to it, and the subsequent truthiness check on that option skips starting the processing loop. Construction, listener registration and scheduler registration all still succeed, which is why the boot log is clean and the failure is silent. Factories that simply omit the key — the segment sweep worker is the reference — are unaffected.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| composition root → worker library options | The process builds every worker through a factory; an option forwarded with no value silently overrides a library default instead of deferring to it |
| registered worker → observable liveness | Registration success and consumption are different facts; the boot log only proves the first, so the second needs its own evidence |
| accumulated wait list → processor side effects | A backlog released all at once re-executes work that was scheduled while nothing was consuming |
