## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| orchestrator signal → worker process | SIGTERM begins a drain; SIGKILL arriving early converts a routine deploy into ambiguous send outcomes |
| queue → worker of a different version | During a deploy, payloads written by one version can be read by another |
| killed migration process → the next deploy | An abandoned lock or a half-recorded migration blocks or corrupts every subsequent deploy |
