<objective>
Expand the tracer's single evidence-found path into the full reconciler: the `unknown` terminal verdict, the bounded late-evidence re-scan, the stale-`dispatching` sweep, and the idempotent campaign-counter backfill that keeps an ambiguous send from hanging a campaign.

Purpose: after 11-06, real ambiguous sends flow into `reconciling` continuously. Without this plan a row with no evidence stays ambiguous forever, a `dispatching` row orphaned by a lost Redis job is invisible, and a campaign whose last recipient is ambiguous never completes.
Output: a pure verdict function with versioned windows, the sole-writer resolution widened to the full verdict set, a completion predicate that counts ambiguity, and integration tests for each verdict and for the concurrency guarantee.
</objective>
