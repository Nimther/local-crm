<objective>
Honest failure and emptiness on the contacts, segments and send-log surfaces (OPS-17, D-11 — inline half).

Purpose: `apps/web` today has essentially no `isError` handling — pages branch on `isLoading`/`isFetching` only, so a failed fetch renders as an empty table that looks exactly like "you have no contacts". D-11 requires each data region to own its own inline error state with a Retry control. This plan builds the two shared components and converts the first group of surfaces; plan 15-07 converts the rest.
Output: `QueryErrorState` and `EmptyState` components plus converted contacts, segments and send-log regions.
</objective>
