<objective>
Collapse the nine identical `resolveWorkspaceMember` implementations scattered across route modules into one shared function in `apps/api/src/modules/tenancy/`, exporting the single 404 body constant every membership failure path uses.

Purpose: SEC-14. Nine copies of a security-relevant branch means nine places a future edit can diverge — and anti-enumeration (SEC-10/15, plan 10-04) can only be asserted platform-wide if there is one code path to assert about. This is also the attachment point Phase 15 hangs `workspace_id`/`request_id` log and Sentry tagging on, so it is built once, here.
Output: `resolve-workspace-member.ts` with `resolveWorkspaceMember` + `NOT_FOUND_BODY`, imported by all nine route modules; zero local copies remain.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → route handler | An unauthenticated or non-member caller probing `:slug` values; the response must not reveal which workspaces exist |
| route handler → Better Auth membership API | The authorization fact; the wrapper around it must not add a distinguishable failure mode |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-02-01 | Information Disclosure | nine divergent membership wrappers | high | mitigate | Single implementation with one shared `NOT_FOUND_BODY`; a grep-level assertion proves no second declaration exists |
| T-10-02-02 | Information Disclosure | non-member vs nonexistent workspace | high | mitigate | Both branches send identical status + body; asserted byte-for-byte in the task-1 test |
| T-10-02-03 | Elevation of Privilege | returning `roles` from the resolver | medium | mitigate | `roles` is returned but no caller's authorization logic changes in this plan; existing `requirePermission` guards stay in place and the full API suite must pass unchanged |
| T-10-02-04 | Spoofing | header-to-Headers conversion (`toFetchHeaders`) | low | accept | Unchanged mechanism, already exercised by every existing route test; this plan only moves the call site |
| T-10-02-SC | Tampering | npm/pip/cargo installs | high | accept | No package-manager installs in this plan — no new dependencies (RESEARCH.md § Package Legitimacy Audit) |
</threat_model>
