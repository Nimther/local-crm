<objective>
Turn the codebase's "transaction-local session state only" convention into a machine-enforced CI check, with a fixture that proves the check can fail.

Purpose: SEC-16's second half, and Pitfall 10 — a single connection-scoped session-state statement leaks into the next request or job that reuses the pooled connection, and this becomes a cross-tenant data leak the moment Phase 14 puts PgBouncer in transaction-pooling mode in front of Postgres. The convention has held by discipline since Phase 1; this makes it un-missable.
Output: `scripts/lint-session-state.mjs`, its own fixture-backed test, an npm script, a CI step, and the written rule in CONVENTIONS.md.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pooled connection → next request/job | Session state that outlives a transaction crosses tenant boundaries invisibly |
| CI static job → merged code | The only automated point at which a reintroduced violation can be caught |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-05-01 | Information Disclosure | connection-scoped session assignment | high | mitigate | Repo-wide audit reports any non-transaction-local assignment; blocking CI step in the `static` job |
| T-10-05-02 | Elevation of Privilege | role switch on a pooled connection | high | mitigate | Role switches are reported unconditionally; the accepted mechanism is a separate login role on a separate pool |
| T-10-05-03 | Tampering | audit that silently matches nothing | high | mitigate | A violating fixture with three distinct violations is asserted to produce exactly three reports |
| T-10-05-04 | Tampering | audit suppressed by a blanket marker | medium | mitigate | Marker suppresses only the following statement and requires a reason; both asserted by test |
| T-10-05-05 | Information Disclosure | audit missing a file because the file list is hand-maintained | high | mitigate | The walker enumerates the source tree; Pitfall 8's sixth touchpoint is the recorded precedent for why |
| T-10-05-SC | Tampering | npm/pip/cargo installs | high | accept | No package-manager installs — the script uses Node built-ins only, matching `scripts/lint-migrations.mjs` |
</threat_model>
