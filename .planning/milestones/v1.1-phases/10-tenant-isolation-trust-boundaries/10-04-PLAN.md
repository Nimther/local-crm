<objective>
Prove — and where it does not already hold, make true — that a missing resource and a forbidden (cross-tenant) resource are indistinguishable on every route, including the public invite preview endpoint.

Purpose: SEC-10 and SEC-15. Response-shape differences are an enumeration oracle; the platform currently relies on nine independently-written 404 branches happening to agree. With one resolver in place (plan 10-02), a parameterized sweep can assert the property platform-wide instead of route by route.
Output: a parameterized cross-route sweep test, an invite-endpoint response-identity test, and whatever minimal handler corrections the sweep exposes.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated client → resource route | A member of one workspace probing ids to discover another workspace's resources |
| unauthenticated client → invite preview | A public endpoint keyed by an id; response differences reveal which ids are real |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-04-01 | Information Disclosure | per-route 404 branches | high | mitigate | Parameterized sweep asserts byte-identical status and body for missing vs cross-tenant on every covered route |
| T-10-04-02 | Information Disclosure | `requirePermission`'s independent 404 literal | medium | mitigate | Replaced with an import of the shared constant so the guard and the resolver cannot drift |
| T-10-04-03 | Information Disclosure | invite preview payload breadth | medium | mitigate | Payload reduced to the fields the real consumer reads; an exact-key-list assertion fails on any future addition |
| T-10-04-04 | Information Disclosure | timing difference between missing and forbidden | low | accept | Both paths execute the same query shape; sub-millisecond timing analysis is out of scope for ASVS L1 and is not addressed by response-body uniformity |
| T-10-04-05 | Spoofing | vacuous sweep (both requests failing before the handler) | medium | mitigate | Positive control in the same file asserts the fixture reaches a 200 for the caller's own resource |
| T-10-04-SC | Tampering | npm/pip/cargo installs | high | accept | No package-manager installs in this plan (RESEARCH.md § Package Legitimacy Audit) |
</threat_model>
