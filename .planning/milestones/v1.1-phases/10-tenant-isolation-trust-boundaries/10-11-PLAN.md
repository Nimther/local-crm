<objective>
Reject stale and replayed SendGrid deliveries by bounding the age of the signature timestamp the webhook signature is computed over, defaulting to ten minutes and overridable by environment.

Purpose: SEC-07. The endpoint verifies the ECDSA signature correctly today but accepts a correctly-signed payload of any age, so a captured delivery can be replayed indefinitely. The freshness check attaches beside the existing verification and never re-implements it.
Output: a pure freshness predicate composed into the route's fail-closed path, an environment-overridable window, and boundary tests at exactly 600 and 601 seconds.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet → webhook receiver | Unauthenticated by session; the signature and now its freshness are the only trust anchors besides the path token |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-11-01 | Tampering / Spoofing | replay of a captured valid delivery | high | mitigate | Signature timestamp age bounded to 600 seconds by default; replay-after-window test pins it |
| T-10-11-02 | Spoofing | forged or skewed future-dated timestamp | medium | mitigate | The bound is on absolute difference, so future-dated deliveries beyond the window are rejected too |
| T-10-11-03 | Information Disclosure | distinguishable rejection reasons | medium | mitigate | Stale, malformed, missing-timestamp and bad-signature all take the identical existing 400 path; asserted byte-for-byte |
| T-10-11-04 | Tampering | freshness check replacing rather than composing with verification | high | mitigate | The two are separate predicates combined at the route; a fresh timestamp with a wrong signature is tested to still fail |
| T-10-11-05 | Denial of Service | legitimate deliveries rejected by clock skew | medium | accept | Ten minutes in each direction is a wide tolerance for provider-to-host skew, and the value is environment-overridable without a deploy of new code |
| T-10-11-06 | Tampering | bounding the wrong timestamp field | medium | mitigate | The predicate takes the header value only; an acceptance criterion asserts the worker's per-event extraction is untouched (Phase 13 / CMP-05 owns it) |
| T-10-11-SC | Tampering | npm/pip/cargo installs | high | accept | No package-manager installs in this plan (RESEARCH.md § Package Legitimacy Audit) |
