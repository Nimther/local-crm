The detector fired (`pluralization`, term "second"). The genuine signal in this phase is `chosen`: a value that was a hardcoded constant — the SendGrid mail/send endpoint URL — becomes a parameter.

- **Noun now primary:** the SendGrid mail/send endpoint URL, as a *process-scoped* value.
- **Decision:** `add-alongside`. The real URL remains the default and the only value any production boot uses; the override is an opt-in process-level parameter, not a modelled entity. The identity model is unchanged — nothing is keyed on the endpoint.
- **Accepted debt:** the endpoint is now process-scoped, not per-tenant. That is correct today because every tenant's key targets the same global SendGrid endpoint.

</assumption_delta_decision>
